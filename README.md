# 🚀 OASIS INFOBYTE (OIBSIP) // PYTHON PROGRAMMING INTERNSHIP

**A collection of sleek, modern desktop GUI applications built with Python and CustomTkinter for the Oasis Infobyte Python Programming Internship.**

# 🌟 INTERNSHIP PROJECT CHECKLIST

> Fully satisfies all Beginner and Advanced requirements across all three completed internship tasks with modular, responsive architecture.

| Task | Project Name | Status | Description |
| :--- | :--- | :---: | :--- |
| ⚖️ **Task 2** | **BMI Calculator** | ✅ | Interactive Body Mass Index calculator with real-time metric/imperial health categorization, visual indicators, and input validation. |
| 🔐 **Task 3** | **Password Generator** | ✅ | Cryptographically secure password generator featuring customizable character sets, length sliders, animated settings toggles, and clipboard integration. |
| 🌤️ **Task 4** | **Nexus Weather // 2050** | ✅ | Futuristic desktop Weather & Air Quality Telemetry Suite powered by the OpenWeatherMap API, featuring dynamic wallpapers, IP auto-location, and extended AQI tracking. |

# ✨ EXTRA ENHANCEMENTS ACROSS PROJECTS

* **Modern Dark-Mode Aesthetics**: Unified slate-and-neon dark UI theme (`#111827`) built with `CustomTkinter` for a consistent, futuristic desktop workstation feel.
* **Non-Blocking Concurrency**: Background daemon threading (`threading.Thread`) and thread-safe UI callbacks (`self.after`) ensure smooth performance during live API calls.
* **Smart Validation & Error Handling**: Built-in GUI status bars and defensive exception handling prevent crashes from invalid inputs or offline states.
* **Modular & Maintainable Codebase**: Clean separation between GUI event controllers and core logic engines across repository folders.

## 🛠️ REQUIREMENTS & INSTALLATION

All applications require **Python 3.8 or higher** along with external libraries for graphical rendering and API networking.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/nirajjain101010-code/OBSIP.git
cd OBSIP
```

### 2️⃣ Install Dependencies

```bash
pip install customtkinter requests pillow
```

### 3️⃣ Run Any Task Application

Navigate to the respective task directory and execute its main Python script:

```bash
# Run Task 2: BMI Calculator
cd Python-Task2-BMICalculator/Python-Task2-BMICalculator
python bmi_calculator.py

# Run Task 3: Password Generator
cd ../../Python-Task3-PasswordGenerator/Python-Task3-PasswordGenerator
python password_generator.py

# Run Task 4: Nexus Weather // 2050
cd ../../Python-Task4-Basic_Weather_App/Weather_App
python weather_app.py
```

## 💡 HOW TO USE

1. **Task 2 (BMI Calculator)**: Enter your weight and height in the input cards, select your preferred units, and calculate your BMI score alongside instant health category feedback.
2. **Task 3 (Password Generator)**: Adjust the desired password length, use the animated toggle switches to include uppercase, numbers, or symbols, and generate/copy strong passwords in one click.
3. **Task 4 (Weather App)**: Launch the app for automatic IP-based local weather, search any city worldwide, toggle between **°C / °F**, inspect the **0–5000 AQI** telemetry panel, or expand hourly and multi-day forecasts.
